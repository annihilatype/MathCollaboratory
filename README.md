# MathCollaboratory v0.1

Интерактивная математическая лаборатория. Первая версия содержит только **построитель графиков y = f(x)**. Все вычисления происходят в браузере, без сервера, аккаунтов, платных API и внешних ИИ-сервисов.

## Запуск

Требуются Node.js 24 LTS и pnpm 11.25.0. Если pnpm не установлен: `npm install -g pnpm@11.25.0`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173/).

```sh
pnpm typecheck  # TypeScript
pnpm test       # автоматические тесты
pnpm build      # проверка типов и production-сборка в dist/
pnpm preview    # просмотр production-сборки
```

Шрифты MathLive автоматически копируются из установленного пакета в `public/fonts` при установке зависимостей. Во время работы приложения CDN не требуется. Не отключайте postinstall; при необходимости запустите `node scripts/copy-fonts.mjs` вручную.

## Возможности

- Несколько графиков: добавление, редактирование, удаление, цвет и видимость.
- Визуальный ввод MathLive: дроби, степени, квадратные корни, скобки, индексы параметров, физическая и экранная клавиатура.
- `sin`, `cos`, `tan`, `ln`, `log`, `exp`, `abs`, `sqrt`, константы `e` и `π`. Тригонометрия в радианах; `ln` — натуральный логарифм, `log` — десятичный.
- Параметры из одиночных латинских букв (кроме x, e) и с индексами, например `a_1`. Для `a sin(bx)` автоматически предлагаются ползунки a и b. Нажмите «Создать ползунок»; до этого соответствующий график не выводится.
- Диапазон, шаг и значение параметра редактируются через «Настроить». При применении значение округляется к ближайшему шагу от минимума.
- Перетаскивание плоскости, масштабирование колёсиком и кнопками, стандартный масштаб, координаты курсора. Масштабы X/Y согласованы, в том числе после изменения размера окна.
- Светлая/тёмная тема, базовая адаптация для узких экранов.
- Автосохранение выражений, цветов, видимости, параметров и темы в localStorage. «Сбросить» восстанавливает исходные примеры и масштаб после подтверждения. Область просмотра не сохраняется.

## Архитектура

```text
src/App.tsx                    оболочка и связывание состояния
src/components/MathEditor.tsx  редактор MathLive и клавиатура
src/components/Graph.tsx       координатная плоскость JSXGraph
src/components/ParameterControl.tsx  настройки ползунков
src/math/expression.ts         преобразование LaTeX, проверка AST, вычисления
src/math/sample.ts             адаптивная выборка графиков и разрывы
src/state/store.ts             модель, исходные данные и проверка сохранений
src/math/expression.test.ts    тесты преобразований, вычислений и сохранения
```

JSXGraph выбран за интерактивную координатную плоскость, масштабирование/перемещение и одинаковую физическую длину единиц по осям. Документация: [JSXGraph Board](https://jsxgraph.org/docs/JXG.Board_.html), [MathLive](https://mathlive.io/mathfield/api/).

math.js используется только для синтаксического разбора. Приложение проверяет каждый узел дерева и вычисляет его собственным интерпретатором с разрешённым набором операторов/функций. Пользовательские выражения не передаются в `eval`, `Function`, `math.evaluate`, `compile` или JessieCode. Присваивания, доступ к свойствам, массивы, произвольные вызовы и неизвестные команды отклоняются.

Выборка уточняется по ошибке в экранных пикселях. Неопределённые значения и неразрешённые скачки разделяются NaN-разрывами; пересчёт выполняется при редактировании, изменении параметров и области просмотра.



## GitHub Pages

Репозиторий: [annihilatype/MathCollaboratory](https://github.com/annihilatype/MathCollaboratory).

Адрес приложения после успешного развёртывания: [annihilatype.github.io/MathCollaboratory](https://annihilatype.github.io/MathCollaboratory/).

Конфигурация находится в `.github/workflows/pages.yml`. При push в `main` (или ручном запуске) она устанавливает зависимости по lockfile, выполняет тесты, проверку типов, сборку и загружает Pages-артефакт. **Задание публикации выполняется**, только если переменная репозитория `ENABLE_PAGES_DEPLOY` равна строке `true`.

Первичная настройка публикации (для этого репозитория или собственной копии):

1. Подключить именно ваш репозиторий MathCollaboratory и перенести подготовленные файлы в него. Если основная ветка называется иначе, заменить `main` в workflow.
2. В GitHub открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. В **Settings → Secrets and variables → Actions → Variables** создать переменную `ENABLE_PAGES_DEPLOY` со значением `true`. Это явное включение публикации.
4. Отправить изменения в `main` либо открыть **Actions → Build and deploy GitHub Pages → Run workflow**.
5. Дождаться успешных заданий `build` и `deploy`. Публичная ссылка появится у окружения `github-pages` и в Settings → Pages. Ожидаемый формат для обычного репозитория: `https://<владелец>.github.io/MathCollaboratory/`.

После включения каждый push в `main` обновляет сайт автоматически, только если проверки проходят. Для остановки будущих публикаций удалите переменную или установите `false`; уже опубликованный сайт это не удаляет. Статус последней публикации доступен во вкладке Actions.

Официальная инструкция: [GitHub Pages с собственным workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Границы v0.1

Поддерживаются явные вещественные функции от x. Не реализованы неявные/параметрические кривые, комплексные значения, системы, интегралы, произвольный LaTeX и корни с заданным индексом. Неподдерживаемый ввод показывает ошибку. Ограничение — 50 выражений, 500 символов и 150 узлов на выражение.

Численная выборка не является символическим анализом: экстремально узкие особенности или очень высокочастотные колебания могут потребовать приближения. Вблизи очень крутых участков возможны небольшие консервативные разрывы.

Сборка предупреждает о размере JS и о внутреннем `eval` в неиспользуемом парсере JessieCode библиотеки JSXGraph; пользовательский ввод до этого парсера не доходит. Это не ошибка сборки. Дальнейшая оптимизация размера библиотек остаётся возможным улучшением.

### Комплексные отображения v0.3

В комплексном режиме включите «Отображение» и введите, например, `z^2`,
`1/z`, `conj(z)` или `exp(z)`. Исходные точки можно перетаскивать; их образы
обновляются в независимой плоскости w. Окружности и отрезки `segment(a,b)`
отображаются параметрически с ограниченной адаптивной дискретизацией.
[Синтаксис, архитектура, ограничения и снимки](docs/complex-mappings-v0.3.md).
