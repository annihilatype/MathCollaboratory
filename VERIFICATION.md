## Стабилизация v0.1.1

Проверено 10 ноября 2026 года в Linux / Chromium:

- `pnpm test`: 64 модульных теста, включая все исходные 51 тест.
- `pnpm typecheck`: успешно.
- `pnpm build`: успешно. Существующие предупреждения JSXGraph об eval и Vite о размере bundle остаются.
- `CHROMIUM_PATH=/usr/bin/chromium pnpm test:browser`: 8 регрессионных браузерных тестов.
- Браузерные проверки покрывают отклонение слишком длинного ввода и перезагрузку, восстановление отдельных повреждённых записей, тригонометрический ввод, совпадение параметра с HTML range и сохранённым значением, модальность/Tab/Shift+Tab/Escape/возврат фокуса, доступные имена после удаления и перестановки с сохранением ключей React.

Новый длинный ввод отклоняется с сообщением и возвратом предыдущей формулы. Длинные формулы из прежних сохранений восстанавливаются целиком для редактирования; вычисление блокируется проверкой длины. Некорректная запись больше не сбрасывает остальные выражения, параметры и тему. Невосстановимые записи и повторные id пропускаются отдельно.

`sin x²` означает `sin(x²)`, `sin²(x)` — квадрат синуса. Для неоднозначных аргументов вроде `sin 2x` требуются скобки. Степени тригонометрических функций поддерживают вложенные аргументы.

Значения параметров округляются к достижимым значениям HTML range относительно минимума. Если верхняя граница не кратна шагу, последним достижимым значением будет ближайшее значение ниже неё. Нулевой, слишком большой и непредставимый с доступной числовой точностью шаг отклоняется.

Запуск браузерных тестов на новой машине:

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm test:browser
```

Для системного Chromium можно задать `CHROMIUM_PATH`. Проверки PR запускаются отдельным workflow без публикации. Реальные Safari/iOS/Android и физический ввод с разных клавиатур не проверялись; формулы в регрессионных тестах передаются через MathLive и событие input. Мобильная компоновка и размер загрузки остаются вне объёма шести исправлений.
