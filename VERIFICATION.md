# Проверки v0.1

Выполнено 8 ноября 2026 года, локально на macOS.

- Установка зависимостей `pnpm install --frozen-lockfile` завершена успешно, включая esbuild и копирование шрифтов.
- TypeScript: `tsc --noEmit` — без ошибок.
- Vitest: 51 тест — успешно. Покрыты дроби, степени, квадратный корень, тригонометрия, логарифмы, e/π, модуль, параметры и индексы; недопустимые конструкции; неопределённые значения; разрывы 1/x, сдвинутой гиперболы и tan; восстановление/валидация сохранения.
- Production-сборка Vite — успешно. Есть предупреждения о размере JS и внутреннем eval в JSXGraph JessieCode. Приложение не передаёт в него пользовательские выражения.
- Сервер разработки запущен, интерфейс открыт в браузере.
- В браузере проверены исходные парабола и синусоида; добавление 1/x и sqrt(x); замена формулы на x² экранной клавиатурой; ошибочное x+; обнаружение параметра b и создание ползунка; изменение параметра a и настроек диапазона/шага; удаление и скрытие функции; светлая/тёмная темы; перезагрузка с восстановлением состояния; приближение, масштаб колёсиком, перетаскивание, стандартный масштаб и координаты курсора; подтверждение сброса и возврат двух исходных примеров.
- Проверены узкая компоновка и настольная компоновка 1280×800. Это не полное тестирование всех мобильных браузеров.
- Статическая сборка открыта через HTTP по `/MathCollaboratory/`. HTML, JavaScript, CSS и все 20 запрошенных файлов шрифтов возвращают HTTP 200. Ошибок приложения в консоли не обнаружено.
- Смена цвета реализована; нативный диалог выбора цвета отдельно автоматически не проверялся.
- GitHub Actions выполнен успешно: установка, 51 тест, TypeScript, production-сборка и публикация Pages. [Первый успешный запуск](https://github.com/annihilatype/MathCollaboratory/actions/runs/42423895021).
- Публичный адрес: https://annihilatype.github.io/MathCollaboratory/. Последующие push в main автоматически запускают проверки и обновление сайта.
